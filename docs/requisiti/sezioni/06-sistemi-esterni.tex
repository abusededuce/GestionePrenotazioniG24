\subsection{Interfacce con sistemi esterni (IS)}
Il sistema \textbf{non interagisce con sistemi esterni}: non usa servizi di posta, sistemi informativi di ateneo o altre applicazioni. Il file dell'archivio è creato e letto solo dall'applicazione ed è descritto tra le esigenze di dati (ED4.1–ED4.5). Per questo non sono definiti requisiti IS.
